## 📖 معرفی و هدف برنامه

زمانی که فیلترشکن، وی‌پی‌ان یا پروکسی تونل (مانند WireGuard, OpenVPN, v2ray, Sing-box, Nekoray, Clash, Tailscale) در ویندوز فعال است، تمام ترافیک سیستم وارد تونل رمزنگاری‌شده می‌شود. این موضوع معمولاً باعث مشکلات متعددی می‌شود:
- افت سرعت و پینگ بالا در بازی‌های آنلاین (Steam, DOTA, CS2, Valorant و ...).
- باز نشدن یا بلاک شدن وب‌سایت‌های بانکی، خدمات دولتی و داخلی به دلیل داشتن IP خارجی.
- مصرف ترافیک بین‌الملل برای دانلودهای حجیم داخلی (IDM, تورنت و ...).

**BiFlow** به شما این امکان را می‌دهد تا بدون نیاز به خاموش کردن فیلترشکن، برنامه‌های دلخواه خود را مستقیماً از کارت شبکه فیزیکی (وای‌فای یا کابل شبکه) عبور دهید؛ در حالی که سایر برنامه‌ها و کل سیستم همچنان امن در داخل تونل VPN باقی می‌مانند.

```
                           ┌───────────────────────────────┐
                           │         سیستم ویندوز          │
                           └───────────────┬───────────────┘
                                           │
                 ┌─────────────────────────┴─────────────────────────┐
                 ▼                                                   ▼
     [ برنامه‌های عادی سیستم ]                              [ برنامه‌های دارای بای‌پس ]
     (مرورگر، تلگرام، دیسکورد)                             (استیم، بازی‌ها، دانلود منیجر)
                 │                                                   │
                 ▼                                                   ▼
       ┌───────────────────┐                              ┌─────────────────────┐
       │   کارت شبکه VPN   │                              │   هوک Winsock بای‌فلو │
       └─────────┬─────────┘                              └──────────┬──────────┘
                 │                                                   │
                 ▼                                                   ▼
          (مسیر رمزنگاری‌شده)                                    (مسیر مستقیم اینترنت)
       ┌───────────────────┐                              ┌─────────────────────┐
       │     سرور VPN      │                              │ کارت شبکه فیزیکی LAN│
       └───────────────────┘                              └─────────────────────┘
```

## ✨ ویژگی‌های کلیدی

- **🚀 ۱۰۰٪ پرتابل و بدون نیاز به نصب درایور:** بدون ایجاد کارت شبکه‌های مجازی دردسرساز (TAP/TUN)، بدون درایورهای نامطمئن، و بدون هرگونه خطر بلو اسکرین (BSOD). در قالب یک فایل اجرایی مستقل و سبک (`BiFlow.exe`).
- **⚡ رهگیری سوکت در سطح بومی Winsock:** تغییر مسیر بسته‌های شبکه مستقیماً در لایه ویندوز سوکت (`connect`, `WSAConnect`, `sendto`, و متد `bind` برای `ConnectEx`) از طریق DLL هوک بومی ۶۴ بیتی با کارایی فوق‌العاده بالا.
- **🌐 شناسایی بلادرنگ کارت‌های شبکه (۰ میلی‌ثانیه):** استخراج فوق‌سریع آداپتورهای فیزیکی، گیت‌وی‌ها و وضعیت ارتباط از طریق Win32 API بدون هیچ‌گونه تأخیر ناشی از پاورشل یا WMI.
- **📊 پایش ارتباطات شبکه زنده:** نمایش پردازه‌های در حال اجرایی که در لحظه در حال ارسال و دریافت داده روی IPv4 و IPv6 هستند.
- **🛡️ قطع آنی اینترنت و ایزولاسیون برنامه با یک کلیک:** مسدودسازی سریع دسترسی برنامه به اینترنت از طریق Windows Defender Firewall و پاره کردن آنی نشست‌های فعال TCP با `SetTcpEntry`.
- **🚀 حالت اجرای مستقیم (Direct Launch):** امکان اجرای هر بازی یا برنامه مستقیماً از داخل محیط BiFlow به‌طوری‌که پیش از اولین اتصال شبکه، هوک بای‌پس اعمال شده باشد.
- **📋 مدیریت پروفایل‌های چندگانه:** امکان ساخت و تغییر سریع پروفایل‌ها (پیش‌فرض، گیمینگ، استریم، کار) با قابلیت ذخیره‌سازی خودکار و بازگردانی (Revert).
- **🗕 مینیمایز به سینی سیستم (System Tray):** امکان قرارگیری در گوشه کنار ساعت ویندوز با منوی راست‌کلیک سریع، مانیتورینگ پس‌زمینه و بازگردانی آنی پنجره.
- **🔒 سازگاری با سیستم دسترسی UAC (راه‌اندازی خودکار ادمین):** استفاده هوشمند از Task Scheduler ویندوز تا نرم‌افزار در زمان ورود به ویندوز بدون مسدود شدن توسط UAC، به‌صورت خودکار اجرا شود.

## 🚀 راهنمای سریع استفاده

### ۱. دانلود برنامه
آخرین نسخه کامپایل‌شده را از بخش [Releases گیت‌هاب](https://github.com/PishiKuchulu/BiFlow/releases) دانلود کنید:
- فایل تکی اجرایی: `BiFlow.exe`
- پکیج فشرده پرتابل: `BiFlow-Portable-Windows-x64.zip`

### ۲. نحوه استفاده
1. فیلترشکن یا پروکسی تونل خود را وصل کنید (WireGuard, OpenVPN, v2ray, Sing-box, Tailscale, Clash و ...).
2. نرم‌افزار **`BiFlow.exe`** را با دسترسی ادمین (Run as Administrator) اجرا کنید.
3. در تب **🌐 Network Adapters** مطمئن شوید کارت شبکه فیزیکی واقعی شما (Wi-Fi یا کابل Ethernet) انتخاب شده است.
4. در تب **📱 Applications** برنامه مورد نظرتان را پیدا کنید (یا با دکمه **Browse .exe** فایل برنامه را دستی انتخاب کنید).
5. روی **⚡ Enable Direct Bypass** یا **🚀 Launch Direct** کلیک کنید.
6. کار تمام است! ترافیک برنامه منتخب شما از این لحظه مستقیماً و با پینگ و سرعت حداکثری از اینترنت فیزیکی شما رد می‌شود.

## 🛠️ ساختار فنی و زیربنایی

| بخش | فناوری | وظیفه در سیستم |
| :--- | :--- | :--- |
| **رابط کاربری** | Rust 2021 + `egui` / `eframe` | محیط گرافیکی دارک، پاسخگویی بالا، ذخیره پروفایل‌ها |
| **تلمتری شبکه** | Win32 `IP Helper` API | دریافت وضعیت کارت‌های شبکه و تفکیک آداپتورهای مجازی |
| **پایش کانکشن‌ها** | جدول‌های `MIB_TCPTABLE` / `UDPTABLE` | شناسایی پروسه‌های با شبکه فعال و قطع ارتباطات باز |
| **موتور تزریق** | Win32 Toolhelp + `CreateRemoteThread` | تزریق امن DLL هوک ۶۴ بیتی به حافظه پردازه هدف |
| **هوک سوکت** | زبان C بومی + `MinHook` | بایند کردن سوکت خروجی به IP کارت شبکه فیزیکی |
| **فایروال** | Windows Defender Firewall | تعریف رول‌های بلاک Inbound و Outbound |
| **استارت‌آپ ویندوز** | زمان‌بندی ویندوز (`schtasks`) | اجرای خودکار با بالاترین سطح دسترسی در لاگین کاربر |

## 🔨 کامپایل از سورس‌کد (Building)

### پیش‌نیازها
- سیستم‌عامل ویندوز ۱۰ یا ۱۱ (نسخه ۶۴ بیتی)
- ابزار کامپایلر Rust با تارگت MSVC (`x86_64-pc-windows-msvc`)
- کامپایلر ویژوال استودیو (Visual Studio C++ Build Tools)

### مراحل ساخت
مخزن را کلون کنید:
```powershell
git clone https://github.com/PishiKuchulu/BiFlow.git
cd BiFlow
```

کامپایل نسخه نهایی:
```powershell
cargo build --release
```

یا اجرای اسکریپت بیلد خودکار:
```powershell
.\scripts\build-release.ps1
```

فایل نهایی در مسیر زیر ایجاد خواهد شد:
```
BiFlow.exe
```
